# StudentDays.co — Antigravity starter bundle

## Included files
- `references/StudentDays.co-reference.html`: primary website reference.
- `references/StudentDays.co-alternate-reference.html`: alternate HTML reference.
- `assets/studentdays-hero.jpeg`: exact supplied lake photo for intro and homepage hero.
- `ANTIGRAVITY_MASTER_PROMPT.md`: complete implementation prompt.

## How to use
1. Extract this ZIP into a clean working directory or copy these reference files into the intended Antigravity workspace.
2. Open the extracted folder in Antigravity.
3. Open `ANTIGRAVITY_MASTER_PROMPT.md`, copy the full prompt, and paste it into Antigravity.
4. If Antigravity has trouble accepting a long request, ask it to read `ANTIGRAVITY_MASTER_PROMPT.md` from the workspace and follow it, then implement in phases. Keep the reference files in the workspace.
5. Make sure the existing StudentDays mobile app is backed up or in a separate directory/repository. Do not run the prompt inside a directory that risks overwriting unrelated app files.

This bundle contains reference materials and instructions, not a completed website implementation. Antigravity should create the actual website code after inspecting the workspace.
